SIP Project: T.A.Q.

Technical, Analytical, Quantitative — an AI-assisted trading journal analyzer.

Project Description

T.A.Q. is an AI-assisted trading journal analyzer that turns a trader's raw trade history into a clear quantitative performance breakdown and a plain-language review of where their edge is — and where it leaks. It computes the metrics that actually matter and uses an AI layer to explain them like a coach, while keeping every byte of the user's data private on their own device.

Problem Statement

Most traders record every trade but analyze none of them. Spreadsheets are intimidating, and the few analytics tools that exist hand back raw numbers without explaining what they mean. As a result, traders rely on memory and gut feel instead of the one dataset that actually reflects their edge: their own results.

Project Scope

  • CSV journal upload and parsing from any trading platform
  • Automated performance metrics — profit factor, expectancy, drawdown, payoff ratio, streaks, risk-adjusted return
  • Cumulative equity-curve visualization
  • AI-generated written performance review
  • An edge verdict: confirmed, marginal, or unproven
  • 100% client-side privacy — journal data never leaves the user's device

Target Market

  • Retail discretionary traders
  • Algorithmic and systematic traders
  • Proprietary trading firm traders and evaluation candidates
  • Trading educators and mentors
  • Anyone keeping a manual trade journal

Innovation Claim

Innovation Claim

T.A.Q. is the first tool to pair full automated trade-performance analytics with an AI reviewer that reads a trader's own results and explains them like a coach — bridging the gap between raw statistics calculators and generic trading advice, while keeping every byte of the user's data private on their own device.

Prototype / Proof of Concept

The prototype lets a trader upload a CSV, computes the full metric suite, renders an equity curve, and returns a written AI assessment with an edge verdict. It is currently in development; the planned build phases are below.

Phase 1

Metrics engine

CSV parsing, column mapping, and the full statistics layer.

Phase 2

Visualization

Equity curve and at-a-glance metrics dashboard.

Phase 3

AI reviewer

An AI layer that reads the metrics and writes the assessment.

Phase 4

Deploy

Serverless function to keep API keys server-side; ship it live.
